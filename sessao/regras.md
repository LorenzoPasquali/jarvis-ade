# Regras do senhor para o Jarvis

Cada regra é um item `- ` com o projeto (ou "todos") e a ação que o Jarvis pode fazer sozinho.
Exemplo de formato (não é uma regra ativa):

    - app-analise-saude: pode aprovar rodar testes; push só com o senhor.

O Jarvis acrescenta e remove regras aqui quando o senhor pede.
